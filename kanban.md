# Kanban SeniorAide - User Stories & Tâches

## Backlog
- **US-01 : Inscription / connexion utilisateur**  
  Développer le formulaire d’inscription et de connexion avec email/mot de passe, hash des mots de passe et confirmation visuelle.  
  Labels : `front`, `back`, `sécurité`

- **US-02 : Questionnaire onboarding**  
  Créer le questionnaire initial (5-10 questions) et stocker les réponses en base.  
  Labels : `front`, `back`

- **US-03 : Tableau de bord**  
  Afficher les rappels du jour et l’état des actions de l’utilisateur.  
  Labels : `front`

- **US-04 : Gestion rappels CRUD**  
  Ajouter, modifier, supprimer les rappels et marquer comme fait.  
  Labels : `front`, `back`

- **US-05 : Gestion contacts d’urgence CRUD**  
  Ajouter, modifier, supprimer contacts d’urgence de l’utilisateur.  
  Labels : `front`, `back`

- **US-06 : Déconnexion utilisateur**  
  Implémenter la déconnexion avec destruction de session ou JWT.  
  Labels : `front`, `back`

- **US-07 : Suppression de compte**  
  Permettre la suppression totale du compte et des données (RGPD).  
  Labels : `front`, `back`

- **US-08 : API sécurisée / routes protégées**  
  Sécuriser toutes les routes et vérifier les permissions utilisateur.  
  Labels : `back`, `sécurité`

- **Sécurité : XSS, CSRF, injections SQL**  
  Implémenter la prévention contre les failles courantes côté serveur et front.  
  Labels : `sécurité`

- **Tests fonctionnels et responsive**  
  Vérifier toutes les fonctionnalités sur mobile et desktop.  
  Labels : `test`

- **Documentation README + captures d’écran**  
  Créer un README complet avec instructions et screenshots.  
  Labels : `documentation`

- **Déploiement front-end + back-end**  
  Mettre en ligne l’application avec nom de domaine et SSL.  
  Labels : `déploiement`
